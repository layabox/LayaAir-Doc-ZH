# 页内编辑器(仅本地预览)

在本地预览模式下,每篇文档页右下角会出现「编辑本页」按钮:

- 点击后右侧滑出 Markdown 编辑面板,**页面整体让位,不遮挡正文**(右侧目录栏暂时隐藏,给正文腾宽度);拖动面板左缘可调宽度
- **输入即实时预览**:停止输入约半秒后,正文区域**增量更新**——只替换真正变化的段落,其余内容(含图片)原封不动,不闪烁。打开面板后的第一次预览因管线差异是整体替换,会闪一次,之后都是增量
- **Ctrl+S 或点「保存」落盘,页面不刷新**:保存后 3 秒内的 full-reload 消息被拦截(实时预览已是保存内容,刷新纯属白闪);外部编辑器(VS Code 等)改文件仍正常热更新
- **双击或划选编辑框里的文字**,预览自动平滑滚动到对应位置,选中词以高亮黄底标出约 2.5 秒
  - 选中点落在**图片引用**内(alt、路径、数字、扩展名都算) → 直接定位到预览中的那张图,加黄色高亮框
  - 选中点落在**链接**内 → 用链接的显示文字定位
  - 其余按**三级精确匹配**:先整行(句子级)匹配、再 ±24 字符上下文、最后按"出现序号"对齐(源文第 k 个该词 → 预览第 k 个);全部失败则不跳,绝不盲搜首个同字
  - frontmatter(标题/描述区)不渲染,选中其中的字不动作;选中代码围栏等纯语法时同样不动作
- **「撤回」按钮**(等同 Ctrl+Z):走原生撤销栈,打字和插入图片都可一步步退
- **不保存就不落盘**:带未保存改动点「关闭」,页面刷新回磁盘上的正式内容,文件不被修改
- **图片**:在编辑框里直接 Ctrl+V 粘贴截图、或把图片文件拖进来,自动上传到本页的 `public/<目录>/img/` 并在光标处插入 `![](…)` 引用
  - **新加图 vs 换图**:光标处直接粘贴 = 新加图,给新序号;**先选中正文里那条图片引用(三击选整行)再粘贴 = 换图**,新图沿用原序号原地覆盖,引用不变,预览立即更新
  - **换图可撤回**:换图前服务端自动备份原图(始终保留最初版本)。**「撤回」按钮和 Ctrl+Z 都能撤换图**——最近一步是换图时按撤回即还原原图;中间打过字则先撤文字(此时可点状态栏的「还原原图」链接直接还原)。**不保存直接关闭,所有被换的图自动写回原图**;按 Ctrl+S 保存才真正提交(备份清除,不再可撤)
  - **自动序号命名(按文档定号)**:乱名(剪贴板的 image.png、微信截图名、哈希名等)自动编号——取**当前文档中光标之前最后一张被引用图片的序号 +1**,已被文档用掉的号自动跳过;本来就符合文档惯例的名字(`1.png`、`3-1.png`,每段最多 3 位数)原样保留
  - 序号只看文档内容,不看目录:粘贴后撤销留下的孤儿文件会在下次粘贴时被同号覆盖回收,所以**粘贴→撤销→再粘贴,序号不变**
  - 文档里正引用着的名字永不覆盖(自动加后缀避让)
  - **保存时垃圾回收**:本会话经编辑器上传、但保存时正文里已不再引用的图片(撤回/删掉了引用),文件一并从目录删除,状态栏会提示清理张数。历史图片(本会话之外的)不做回收,防误删
- 带着未保存的改动点「关闭」,页面自动刷新回磁盘上的正式内容
- 保存引发页面刷新后,面板、光标位置、未保存草稿都会自动恢复
- 样式全部取 Starlight 的 CSS 变量,自动跟随站点明暗主题

## 实时预览的保真度说明

实时预览用 Astro 自带的 markdown 管线渲染,`:::tip` 等提示块手工转成同样的 aside 结构;
唯一差异是代码块高亮用 shiki(正式渲染是 expressive-code),主题略有出入。
**按 Ctrl+S 保存后看到的就是最终效果**。frontmatter(标题/描述)的改动只在保存后生效。

## 上线隔离(重要)

本功能**只存在于 `npm run dev`(本地预览)进程中**:

- `integration.mjs` 在 `astro:config:setup` 里判断 `command !== 'dev'` 直接返回
- 因此 `npm run build` 产出的 `_book/` 中不含任何编辑按钮、脚本或接口(已构建验证零残留)
- 保存接口只允许写 `src/content/docs` 内已存在的 `.md/.mdx`,拒绝路径穿越,不允许新建文件
- 上传接口只允许图片扩展名,只能写入文档对应的 `public/<目录>/img/`,重名自动改名

## 文件

- `integration.mjs` — Astro 集成:dev 模式注入客户端脚本 + 挂载 `/__dev-editor` 读写/预览/上传接口
- `client.js` — 浏览器端 UI(按钮、面板、实时预览、图片上传、状态恢复)

改动任一文件后需重启 dev server 才生效(`touch astro.config.mjs` 即可触发自动重启)。
