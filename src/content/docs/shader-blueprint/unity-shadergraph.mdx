LayaAir 的着色器蓝图在节点能力上已与 Unity ShaderGraph 高度对齐，并提供了
[Unity 资源导出插件](/unity-plugin/)把 `.shadergraph` 批量转换成 `.bps`。本页给出**逐节点对照**，
既服务于手工重建，也说明自动转换时哪些地方会有差异。

:::note[对照表的来源]
下表来自转换器内置的映射表，共 **162 条**。同一行表示：Unity 里的这个节点，在 Laya 蓝图里用
该路径的节点实现，且自动转换时会这样映射。
:::

## 走 custom 兜底的节点

以下 Unity 节点没有一一对应的 Laya 原生节点，转换时生成 `function/custom` 内嵌 GLSL。
功能可用，但在蓝图里表现为一个代码块而不是可视化节点：

| Unity 节点 | 说明 |
|---|---|
| `CustomFunctionNode` | Unity 侧本来就是自定义代码，直译过来是正确做法 |
| `GradientNode` / `SampleGradient` | 渐变数据在编译期已知，转换器把采样内联展开成 `mix` 链 |
| `TriplanarNode` | 三平面映射 |
| `KeywordNode` | 关键字分支 |
| `IsFrontFaceNode` | Laya 有 `logic/isFrontFace`，但输出类型语义不同，暂走 custom |

## 尚未覆盖的节点

以下 Unity 节点目前没有映射，自动转换时会被跳过。手工重建时需要用其他方式实现：

| Unity 节点 | 情况 | 替代方案 |
|---|---|---|
| `SamplerStateNode` | Laya 无独立采样器状态概念 | 采样器设置在纹理资源的导入设置里配置 |
| `ParallaxOcclusionMappingNode` | 需要在循环中反复采样纹理，**受蓝图框架限制无法实现** | 用 `uv/parallax` 单步视差近似 |
| `ParallaxMappingNode` | 语义不匹配（Unity 内部采高度图并自动算切线视线；Laya 取显式标量与视线） | 用 `uv/parallax`，自己接高度与视线 |
| `SplitTextureTransformNode` | 拆纹理的 tiling / offset 元数据 | 自己用 Params 传入 tiling / offset |
| `Texture2DPropertiesNode` | 纹理尺寸等元数据未暴露 | 用 Params 传入尺寸常量 |
| `CalculateLevelOfDetailTexture2DNode` | 纹理 LOD 查询未暴露 | — |
| `GatherTexture2DNode` | 需要 ES 3.1 的 gather | 用四次相邻采样手工模拟 |
| `SceneDepthDifferenceNode` | 需要位置输入 | 用 `sceneDepth` 自己相减 |
| `EyeIndexNode` | VR 眼索引 | — |
| `SubGraphNode` | 转换器不展开 Unity 子图 | 在 Laya 侧用[蓝图函数 `.bpsf`](/shader-blueprint/ide-workflow/#八蓝图函数bpsf)重建 |

## 已知语义差异

即使节点已映射，下面这些地方两边行为不完全一致，迁移后需要检查：

### 没有动态维度推导

Unity 大量节点是「动态维度向量」，会自动为不同维度的输入做广播。**Laya 的多态节点只能锁定一种类型**，
所有输入被统一到同一维度。Unity 图里依赖隐式广播的地方，转过来需要显式用 `append` / `mask` /
`swizzle` 对齐维度。这是两边最主要的结构性差异。

### TimeNode 只有一路输出

Unity 的 Time 节点有 Time / Sine Time / Cosine Time / Delta Time / Smooth Delta 五路输出；
Laya 的 `Time` 是**单个标量**。转换时只取 Time，其余输出会退化。需要 Sine Time 请自己接 `sin`；
Delta Time 类需要引擎逐帧增量，目前无对应。

### 空间语义

Unity 的 `Position` / `Normal Vector` / `Tangent Vector` 带 Space 选项（Object / View / World /
Tangent / AbsoluteWorld）。转换器会读取该设置并选择 Laya 的 OS / WS 版本；但 **View 与 Tangent
空间没有直接对应**，会回落并给出告警。用到这两个空间时请手工用 `math/matrix/transform` 或
`TBNMatrix` 补上。

### 纹理数组的 Index

Unity 的 `SampleTexture2DArray` 是 UV(vec2) + Index(float) 两个输入；Laya 的 `sample2DArray`
是单个 Coord(vec3)。转换后 **Index 会丢失**，需要手工用 `append` 拼成 `vec3(uv, layer)` 再接进去。

### 噪声图案不同

三个噪声节点的整体特征一致，但哈希算法不同，**逐像素图案不会一样**。依赖噪声精确图案的效果
（如特定形状的溶解边缘）迁移后需要重新调 Scale 与阈值。

### 其他细项

- **矩阵主序**：Unity（HLSL）行主序、Laya（GLSL）列主序。手工重建矩阵时注意按列填。
- **法线贴图绿通道**：Unity 用 DirectX 约定，选 Laya 的 `sampler2DNormal(DX)` 才一致。
- **`transform` 的 Normal 模式**按 Direction 近似，非均匀缩放物体上不精确。
- **`ObjectNode`** 在开启 GPU 实例化时取不到逐实例数据。
