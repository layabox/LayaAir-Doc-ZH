着色器蓝图（Shader Blueprint）让开发者用连线的方式构建 Shader，不写一行 GLSL 也能做出完整的
PBR、Unlit、Blinnphong 材质效果。本文档集是着色器蓝图的**完整功能说明**：从概念认知，到 IDE
里的每一步操作，到每个节点的输入输出与模式，再到从 Unity ShaderGraph 迁移时的逐节点对照。

## 能力概览

蓝图右键菜单当前提供 **186 个节点**，分为 12 个一级分类（另有一批供节点内部调用的隐藏实现节点，
以及只能从 Params 面板添加的颜色与纹理资产节点）。下表是各分类的覆盖情况：

:::tip[想快速定位一个节点]
节点手册按**菜单路径**排序，与蓝图编辑器右键菜单的层级完全一致。知道节点名时，直接在对应手册页用
浏览器 Ctrl+F 搜节点名即可；知道 Unity 里叫什么时，先查 [Unity 对照表](/shader-blueprint/unity-shadergraph/)。
:::
