IDE 的基础交互分为键盘输入、快捷键、鼠标交互、鼠标与键盘的功能组合。

本篇介绍 IDE 的基础交互与默认快捷键，便于双手协作、提升开发效率。除非特别说明，下列为 **Windows 默认键**；Mac 上 `Ctrl` 对应 `Command`（源码中以 `mod` 表示跨平台修饰键）。

> 本篇所列多为 IDE 出厂默认值。绝大多数可在菜单 **编辑 → 偏好设置 → 快捷键** 中查看与修改（详见第 6 章）。文中以 Windows 为例书写。

## 1、通用的基础交互

层级面板、属性面板、项目面板等几乎处处会用到，因此先介绍通用交互与全局快捷键。

### 1.1 切换面板显示层级

IDE 功能面板可任意拖拽布局；同一窗口内，点击面板标签可切换显示层级，如图1-1所示。

![图1-1](./img/1-1.gif)

（图1-1）

除了点击标签，还可用下列快捷键聚焦常用面板：

| 功能名称 | 操作 |
| --- | --- |
| 场景面板 Scene | Ctrl + 1 |
| 运行面板 Game | Ctrl + 2 |
| 属性面板 Inspector | Ctrl + 3 |
| 层级面板 Hierarchy | Ctrl + 4 |
| 项目资源面板 Project | Ctrl + 5 |
| 控制台面板 Console | Ctrl + 6 |
| 时间轴面板 Timeline | Ctrl + 7 |

### 1.2 全局编辑与文件、节点操作

#### 1.2.1 撤销、重做与保存

| 功能名称 | 操作 |
| --- | --- |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Y，或 Ctrl + Shift + Z |
| 保存 | Ctrl + S |

> 保存为全局快捷键，后文各模块不再重复说明。Mac 上删除除 `Delete` 外，还可用 `Command + Backspace`。

#### 1.2.2 重命名：F2

无论是节点名还是文件、文件夹，使用快捷键 `F2` 即可进入重命名模式。

鼠标操作：`单击选中` 后间隔约半秒再 `单击`，效果等同于 F2。

#### 1.2.3 复制、剪切、粘贴、删除、选中

在层级面板、项目面板、场景面板等位置，选中节点或文件后可用：

| 功能名称 | 操作 |
| --- | --- |
| 拷贝 | Ctrl + C |
| 剪切 | Ctrl + X |
| 粘贴 | Ctrl + V |
| 原位粘贴 | Ctrl + Shift + V |
| 粘贴为子节点 | 无默认键，可在偏好设置中绑定 |
| 删除 | Delete（Mac 亦可用 Command + Backspace） |
| 全选 | Ctrl + A |
| 选中单个 | 鼠标左键单击 |
| 多选 | Ctrl + 鼠标左键单击 |
| 不间断多选 | Shift + 鼠标左键单击 |

### 1.3 层级面板的常用操作

#### 1.3.1 创建空节点

除右键菜单外，可用快捷键快速创建空节点：

| 功能说明 | 操作 |
| --- | --- |
| 在根节点下创建一个空子节点 | Ctrl + Shift + N |
| 为当前选中节点创建一个空子节点 | Alt + Shift + N |
| 为当前选中节点（可多选）创建一个空父节点 | Ctrl + Shift + G |

> 2D 空节点为 Sprite，3D 空节点为 Sprite3D。

#### 1.3.2 层级顺序调整快捷键

| 功能说明 | 操作 |
| --- | --- |
| 下移一层 | Ctrl + ↑ |
| 上移一层 | Ctrl + ↓ |
| 移至顶层 / 移至底层 | 无默认键，可在偏好设置中绑定 |

#### 1.3.3 展开全部子节点：Alt + 鼠标左键单击

正常情况下，单击节点前的三角箭头会展开一层子节点。

使用 `Alt + 鼠标左键单击` 三角箭头时，可展开其下全部层级，如图1-2所示。

### 1.4 层级与场景的通用操作

#### 1.4.1 节点视窗聚焦：F

在层级面板或场景中选中节点后，按 `F` 可将视窗摄像机聚焦到该节点，如图1-6所示。

![图1-6](./img/1-6.gif)

（图1-6）

> 鼠标左键双击 3D 节点，也可聚焦。2D/3D 节点的聚焦行为以场景当前视窗类型为准。

#### 1.4.2 复制并粘贴节点：Ctrl + D

在层级或场景中选中 2D/3D 节点后，`Ctrl + D` 可快速复制并粘贴（Duplicate）。

### 1.5 运行预览功能

编辑完成后，IDE 提供 IDE 内预览、浏览器预览、手机扫码预览、桌面端预览等入口，按钮如图1-7所示。

| 功能说明 | 操作 |

| 停止播放 / 暂停继续 / 单步下一帧 | 无默认键，可在偏好设置中绑定 |

### 1.6 其它全局功能

| 功能说明 | 操作 |
| --- | --- |
| 快速搜索 | Ctrl + Alt + P |
| 重载编辑器 | Ctrl + Alt + R |

### 1.7 属性面板操作

#### 1.7.1 属性数值滑动输入

当属性为数字类型时，鼠标移到输入框上会变为双向箭头样式，可沿箭头方向拖动改值，也可点入框后键盘输入。

#### 1.7.2 属性保存：Ctrl + S

属性面板或场景中的修改均可使用 `Ctrl + S` 保存（同 1.2.1）。

## 2、2D 场景视窗交互

当处于 Scene2D 或 2D 预制体节点时，启用 2D 场景视窗。

| 上下滚动视窗内容 | 鼠标滚轮 |
| 缩放视窗内容 | Ctrl + 鼠标滚轮（默认） |
| 2D 场景放大 | Ctrl + = |
| 2D 场景缩小 | Ctrl + - |
| 2D 场景恢复缩放 | Ctrl + 1 |

效果如图2-1所示：

![图2-1](./img/2-1.gif)

（图2-1）

> **说明：**  
> 1. 「缩放热键」可在 **场景视图设置 → 画布** 中改成「仅滚轮缩放」；默认是 `Ctrl + 滚轮` 缩放、单纯滚轮滚动内容。

## 3、3D 场景视窗交互

3D 场景中主要有两类操作：

一是改变视窗摄像机位置与角度，像人眼一样观察场景；

二是调整模型位置、旋转与缩放，摆到合适位置。

> 更系统的图示与说明见 [《3D场景编辑基础交互》](/ide/sceneeditor/basic/)。下文给出与 3.4 源码一致的快捷键与核心操作摘要。

### 3.1 操作视窗摄像机

#### 3.1.1 旋转视窗摄像机：鼠标右键

持续按住 `鼠标右键` 进入旋转模式，屏幕上移动鼠标改变观察角度；松开即退出。效果如图3-1所示。

![图3-1](./img/3-1.gif)

（图3-1）

#### 3.1.2 空间位移视窗摄像机

按住鼠标右键的同时使用下列键做相对方向位移：

| 功能说明 | 操作 |
| --- | --- |
| 摄像机向上位移 | 鼠标右键 + E |
| 摄像机向下位移 | 鼠标右键 + Q |
| 摄像机向左位移 | 鼠标右键 + A |
| 摄像机向右位移 | 鼠标右键 + D |
| 摄像机向前位移 | 鼠标右键 + W |
| 摄像机向后位移 | 鼠标右键 + S |

效果如图3-2所示。

![图3-2](./img/3-2.gif)

（图3-2）

> 上下前后左右为摄像机相对方向，与视角旋转联动。

**加速位移：** 在上述组合上再按住 `Shift`，即：鼠标右键 + Shift +（E、Q、A、D、W、S）。

#### 3.1.3 屏幕内位移视窗摄像机：Q / 鼠标中键

除「右键 + Q/E/A/D」外，还可用 `Q` 或鼠标中键做任意方向平移。

按 `Q` 后，左键拖拽即可平移摄像机，如图3-3所示。

![图3-3](./img/3-3.gif)

（图3-3）

`Q` 会切换工具模式，退出需再切到其它工具（如 W/E/R/T）。临时平移更建议 **中键拖拽**：按下拖动有效、松开自动恢复。

#### 3.1.4 视窗摄像机缩放：鼠标滚轮

滚轮前后移动摄像机（透视下观感像缩放），如图3-4所示。

![图3-4](./img/3-4.gif)

（图3-4）

#### 3.1.5 视窗摄像机绕焦点中心旋转：Alt + 左键拖拽

先选中对象并用 `F` 聚焦，再 `Alt + 左键` 拖拽，可绕焦点旋转，如图3-5所示。

![图3-5](./img/3-5.gif)

（图3-5）

#### 3.1.6 保存与切换摄像机位置

## 5、着色器蓝图编辑器快捷键

本章针对 **着色器蓝图**（Shader Blueprint）。脚本逻辑蓝图的节点快捷键不同，请参阅对应蓝图文档。

### 5.1 生成节点快捷键

在着色器蓝图画布上，**按住**字母/数字键再 **鼠标左键点击** 空白处，可快速生成节点（以下为内置常用项）：

| 功能说明 | 快捷组合键 |
| --- | --- |
| 快速生成 Float 节点 | 1 + 鼠标左键 |
| 快速生成 Vector2 节点 | 2 + 鼠标左键 |
| 快速生成 Vector3 节点 | 3 + 鼠标左键 |
| 快速生成 Vector4 节点 | 4 + 鼠标左键 |
| 快速生成 Boolean 节点 | b + 鼠标左键 |
| 快速生成 If 节点 | i + 鼠标左键 |
| 快速生成 Int 节点 | I + 鼠标左键（注意为大写 I，与 If 的小写 i 不同） |
| 快速生成 Color 节点 | c + 鼠标左键 |
| 快速生成 sampler2D / Time 等（同键） | t + 鼠标左键 |

> 部分节点会共用同一快捷键（例如 `t` 上可能同时有 Time 与 sampler2D 等注册）。实际弹出或创建以当前蓝图版本与节点注册顺序为准；也可通过右键菜单或节点搜索创建。

### 5.2 画布鼠标交互

| 功能说明 | 按键 |
| --- | --- |
| 平移画布 | 鼠标中键或右键按下拖拽 |
| 缩放画布 | 鼠标滚轮 |

> 着色器蓝图完整说明见 [《蓝图编辑模块》](/ide/shaderblueprint/)。

## 6、在偏好设置中自定义快捷键

菜单 **编辑 → 偏好设置**，打开后选择 **快捷键**（对应类型 `ShortcutKeys`），即可查看与修改默认绑定，分组大致如下：

| 分组 | 涵盖内容示例 |
