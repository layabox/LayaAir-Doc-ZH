## 1、启动页配置

启动页是指**游戏正式进入加载与运行流程之前显示的首个画面**，用于展示游戏或公司的标识（请并列显示引擎的LOGO标识），同时在视觉上缓冲加载引擎基础库带来的黑屏等待时间。

如果不进行任何设置，系统仅使用引擎内置的默认启动图标。开发者也可以根据项目需求，自定义启动页的显示内容与样式，以提升产品的专业感与品牌识别度。

### 1.1 激活

用于控制是否启用启动页。

勾选后，游戏在正式进入运行阶段前将显示启动页；

未勾选时，启动页功能关闭，游戏将直接进入加载或首个场景。

### 1.2 背景颜色

用于设置启动页的背景颜色。

勾选后，可自定义启动页的纯色背景，常用于与 LOGO 颜色搭配，避免默认背景颜色与自定义 LOGO 不协调带来的视觉突兀。

### 1.3 图片

用于指定启动页中显示的图标或图片内容。

默认情况下使用引擎自带的图标；当开发者自定义图片时，**图片资源必须放置在 `bin` 目录下**，以确保在启动阶段能够被正确加载。

建议使用清晰、比例合适的图片资源，以适配不同分辨率设备。

### 1.4 适配

用于设置启动页图片在屏幕中的显示与缩放方式，支持以下几种模式：

- **center**（居中）：图片居中显示，不进行缩放
- **fill**（填充）：拉伸图片以填满屏幕，可能产生变形
- **contain**（包含）：在保持比例完整显示图片的前提下，缩放至全屏尺寸，可能留有空白
- **cover**（覆盖）：在保持比例的前提下缩放至覆盖整个屏幕，可能裁剪部分内容

开发者可根据图片设计与平台特性选择合适的适配模式。

### 1.5 最小显示时间

用于设置启动页的最短显示时长，单位为秒。

即使游戏初始化过程非常快，启动页也会至少显示该时间，以避免一闪而过，影响观感。

该参数通常用于保证品牌展示的完整性。

### 1.6 允许在预览中激活

用于控制启动页是否在预览模式下生效。

勾选后，在编辑器或预览环境中即可看到启动页效果；

未勾选时，启动页仅在正式发布后的版本中显示，便于开发阶段快速调试而不受干扰。

## 2、其它说明

虽然在技术手段上，我们开放了启动页的图片更换以及是否显示的能力。

但建议开发者与自定义 LOGO 并列保留 LayaAir 引擎品牌 LOGO 的显示，

如因特殊情况，不显示启动页时，请在启动页或加载页的任意可见位置，保留引擎著作权的文字标识，具体如下：

```
Powered by LayaAir Engine
```
