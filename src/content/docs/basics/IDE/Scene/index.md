## 1、场景面板的作用

场景面板是 LayaAir IDE 中查看和编辑场景内容的可视化工作区。开发者可以在其中选择对象，使用移动、旋转、缩放、对齐等工具调整对象，也可以将资源或节点类型直接拖入场景完成创建。编辑场景时，通常先在层级面板中定位对象、确认父子结构，再在场景面板中进行可视化操作，并通过属性面板查看或精确修改参数；搭建关卡时，也可以在这里布置地形、灯光、障碍物和角色等内容。场景面板同时支持 2D 和 3D 内容，并会根据当前场景和编辑对象显示相应的视图与工具。

## 2、Gizmos 与辅助可视化

### 2.1 认识 Gizmos

Gizmos 是显示在场景面板中的编辑辅助信息，用于标识摄像机、灯光、反射探针等不容易通过普通画面辨认的对象。它们主要服务于场景编辑，不会作为普通游戏画面显示。

Gizmos 不只有对象图标。选中对象后，场景面板还可能显示视锥体、照射范围、方向、边界等辅助线框；部分辅助线框带有可拖动的编辑手柄，可以直接调整对象的范围、角度或尺寸。

| 类型 | 作用 | 常见显示方式 |
| --- | --- | --- |
| 对象图标 | 标识摄像机、灯光和反射探针等对象的位置与类型 | 对象位于当前编辑视图且未被隐藏时显示 |
| 辅助线框 | 表示视口、照射范围、方向或边界 | 通常在选中相应对象后显示 |
| 交互手柄 | 调整对象的范围、角度、尺寸或变换 | 选中对象并进入相应编辑状态后显示 |

:::tip
关闭“显示图标”只会隐藏对象图标，不一定会隐藏选中对象后出现的范围线框和编辑手柄。
:::

### 2.3 Gizmos 显示设置

在 3D 场景工具栏中点击“显示设置”，可以调整场景视窗摄像机和 Gizmos。与 Gizmos 直接相关的设置如下：

| 设置项 | 作用 |
| --- | --- |
| 显示图标（Show Icons） | 显示或隐藏场景中的 Gizmos 对象图标 |
| 图标大小（Icon Size） | 调整 3D Gizmos 图标的显示比例，可设置范围为 `0.1～5` |
| 显示网格（Show Grid） | 显示或隐藏 3D 场景中的参考网格 |
| 选中轮廓（Selection Outline） | 显示或隐藏选中 3D 对象时的轮廓高亮 |

## 3、场景面板中的显示与交互工具

场景面板提供 2D 和 3D 两套独立的编辑视图。打开纯 2D、GUI 或纯 3D 场景时，编辑器会进入对应模式；对于同时包含 2D 和 3D 内容的场景，对不同类型的对象执行聚焦操作时，场景面板会切换到相应视图。两套视图会分别保留上次选择的操作工具，切换后可以继续之前的编辑操作。

### 3.1 2D 场景工具

2D 场景工具主要用于移动编辑视图，以及对 2D 对象进行选择、移动、对齐、排列和尺寸调整。

| 工具类别 | 包含的主要工具 | 主要用途 |
| --- | --- | --- |
| 视图与对象操作 | 视窗移动、对象移动 | 移动画布视图或调整所选对象的位置 |
| 水平对齐 | 左对齐、左右居中对齐、右对齐 | 调整所选对象的水平位置关系 |
| 垂直对齐 | 上对齐、上下居中对齐、下对齐 | 调整所选对象的垂直位置关系 |
| 尺寸与排列 | 相同宽度、相同高度、均匀行距、均匀列距、表格排列 | 批量整理多个对象的尺寸和布局 |
| 显示设置 | 背景颜色、缩放方式、缩放速度、设计参考图 | 调整 2D 编辑环境和参考内容 |
| 视图缩放 | 缩放比例、放大、缩小、恢复 100% | 调整画布的观察比例，不改变对象的实际尺寸 |

2D 显示设置还支持为当前场景配置设计参考图。开发者可以选择图片来源，并调整参考图的偏移、透明度及前后显示层级；这些设置便于按照设计稿搭建界面。

### 3.2 3D 场景工具

3D 场景工具既可以控制场景视窗的观察位置和角度，也可以调整 3D 对象在空间中的位置、旋转和缩放。

| 工具类别 | 包含的主要工具 | 主要用途 |
| --- | --- | --- |
| 视图控制 | 平移、自由观察、围绕焦点观察、缩放 | 调整场景视窗的观察位置、角度和距离 |
| 对象变换 | 移动（`W`）、旋转（`E`）、缩放（`R`）、综合变换（`T`） | 调整 3D 对象的空间状态 |
| 坐标空间 | 局部坐标、全局坐标 | 决定变换手柄采用对象自身方向还是世界坐标方向 |
| 投影模式 | 透视投影、正交投影 | 切换场景视窗摄像机的观察方式 |
| 显示设置 | 摄像机设置、Gizmos 设置 | 调整编辑视图参数和辅助显示 |
| 刷新方式 | 响应式（按需刷新）、实时刷新 | 控制场景视图的更新频率；响应式仅在内容变化时刷新，实时刷新最高约为 30 FPS |

3D 显示设置中的摄像机参数只用于调整编辑视图，包括视野范围、近裁剪面、远裁剪面、缩放速度和移动速度。它们与场景中作为游戏对象使用的摄像机属性不是同一组设置。

| 摄像机参数 | 作用 |
| --- | --- |
| Field of View | 调整透视模式下的视野角度，可设置范围为 `4～120` |
| Near Plane | 设置编辑视图摄像机的近裁剪面，最小值为 `0.01` |
| Far Plane | 设置编辑视图摄像机的远裁剪面 |
| Zoom Speed | 调整场景视窗的缩放速度，可设置范围为 `0.1～10` |
| Transform Speed | 调整场景视窗摄像机的移动速度，可设置范围为 `0.1～10` |
| Post Process | 控制编辑视图是否显示后处理效果 |
| Depth Texture | 控制编辑视图使用的深度纹理 |

![3D 场景中的显示与交互工具](./img/3d-toolbar.png)

#### 3D 工具效果对比

局部坐标以对象自身的旋转方向为基准，全局坐标以场景的世界坐标方向为基准。对于已经旋转的对象，两种模式下的变换手柄方向会有明显区别。切换坐标模式不会直接改变对象的位置、旋转或缩放，只会改变变换手柄的轴向，以及后续变换操作采用的参考坐标系。下图中的对象位置和旋转保持不变，仅切换了局部坐标与全局坐标模式。
