场景面板是引擎编辑器的核心功能之一，承担着可视化编辑与空间管理的职责。

## 1、场景面板的作用

场景面板是连接"数据逻辑"与"空间直觉"的桥梁，大幅降低了开发者在脑海中抽象空间关系的认知负担，是所见即所得工作流的核心体现。

### 1.1 可视化编辑环境

场景面板提供一个 3D 和 2D 的实时视口，让开发者能够直观地看到游戏世界的构成，而不必依赖坐标数字来理解空间关系。

### 1.2 对象的摆放与变换

开发者可以直接在场景面板中通过拖拽、旋转、缩放等操作来放置游戏对象，调整其位置、朝向和大小，配合变换工具（移动/旋转/缩放）完成精确布局。

### 1.3 层级与空间关系管理

配合层级面板，场景面板能够直观展示父子对象之间的空间嵌套关系，方便开发者理解场景结构。

### 1.4 场景构建与关卡设计

关卡设计师在场景面板中直观的搭建地形、放置障碍物、布置灯光、摆放 NPC 等，完成整个关卡的空间叙事与功能布局。

### 1.5 **Gizmos 与辅助可视化** 

场景面板会渲染各种辅助图标（Gizmos），例如碰撞体边界、光源范围、摄像机视锥体、导航网格等，这些信息在最终游戏中不可见，但对开发阶段至关重要。

## 2、场景面板中的显示与交互工具

场景面板的交互工具分为 **2D** 与 **3D** 两套，相互独立，分别服务于 2D 场景与 3D 场景的编辑需求。场景面板会根据层级面板中当前的事件焦点，自动切换所显示的节点内容与对应的交互工具。

当事件焦点位于 **Scene2D 节点或其子节点**时，场景面板将仅显示 2D 节点内容及 2D 交互工具，如图 2-1 所示。
