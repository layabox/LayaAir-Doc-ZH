本组是「快速入门」里的前置课：先让电脑能写、能跑、能查，再进入 IDE 流程与示例。不必在这里追求语言专家级精通，也**不必背 API**。

完整的按天学习计划，请看 [程序新手路线 · 准备环境与语言](/guides/roadmap/beginner/prepare/)；本页只做侧栏导引与分流。



## 一、推荐阅读顺序

### 1.1 必读

按顺序走完下面三篇，即可进入下一组「基础开发模块与流程」：

1. [搭建基础开发环境](/basics/developmentenvironment/download/)  
   安装 IDE、关联编码工具与浏览器，保证能创建/打开工程。

2. [TS 语言基础](/basics/language/)  
   按「够用就走」补齐 TypeScript / JavaScript 最小语法；细节可边做项目边查。

3. [如何阅读 LayaAir 的 API](/basics/developmentenvironment/api/)  
   学会搜索类与方法、读懂继承与签名。引擎类很多，关键是会查，而不是背下来。

### 1.2 可选（用 AI 辅助开发时再看）

习惯用大模型写代码或查资料时，可先浏览：

- [AI 协同开发环境](/basics/developmentenvironment/aigc/) —— AI 问答、AIGC、代码助手与 Agent 的整体图景  

组外还有更细的工具说明（不挡主线，需要时再点开）：

- [LayaAir-MCP](/basics/developmentenvironment/ide-mcp/)  
- [LayaAir CLI](/basics/developmentenvironment/cli/)  
- [LayaIdea](/basics/developmentenvironment/layaidea/)  
- [CodingMCP](/basics/developmentenvironment/codingmcp/)



## 二、本组读完后去哪

| 目标 | 去向 |
| --- | --- |
| 跑通第一个工程 | [开发流程：Hello World](/basics/ide/helloworld/)，或从 [基础开发模块与流程](/basics/ide/) 按目录往下读 |
| 按阶段系统学习 | [程序新手路线](/guides/roadmap/beginner/) |

:::tip[自检]
- IDE 能正常打开，能创建或打开工程  
- 编码工具已关联，能从 IDE 跳到脚本文件  
- 遇到不认识的类名，知道去哪查、怎么读  
- 语言方面：能看懂带类型注解的简单脚本，不怕报错红线  
:::
