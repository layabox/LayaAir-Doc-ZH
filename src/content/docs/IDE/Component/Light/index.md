> Author : Charley

3D灯光组件包括方向光、点光源、聚光灯和区域光四种类型。

灯光类型概述和多光源渲染请查看[《3D灯光与阴影》](/3d/light/)。

| 灯光组件 | 说明 |
| --- | --- |
| [方向光 DirectionLightCom](/ide/component/3dlight/directionlight/) | 固定方向的平行光，常用于模拟太阳光 |
| [点光源 PointLightCom](/ide/component/3dlight/pointlight/) | 向四面八方发射光线的球状光源 |
| [聚光灯 SpotLightCom](/ide/component/3dlight/spotlight/) | 从特定方向射出的锥形光源 |
| [区域光 AreaLightCom](/ide/component/3dlight/arealight/) | 从矩形或圆盘表面发射的面光源，仅支持烘焙 |
