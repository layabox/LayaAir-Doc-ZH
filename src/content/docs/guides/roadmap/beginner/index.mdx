本路线把散落在「快速入门」与引擎各章的文档，整理成一条**可按天推进**的学习路径。目标不是一次读完全站，而是：用最短路径做出能跑的东西，再按需查详解。

:::tip[适合谁]
- 第一次接触 LayaAir / 游戏引擎，但有一点编程基础（或愿意同步补一点 TypeScript）
- 想用 IDE 可视化编辑 + 脚本开发，而不是纯手写脚手架
- 目标是 2～4 周内独立做出一个小 Demo，而不是立刻做商业大作
:::

:::caution[不适合当作]
- Unity / Cocos 老司机的差异对照手册 → 请看 [Unity/Cocos 迁移路线](/guides/roadmap/migration/)
- 进阶性能、Shader、发布与工程化 → 请看 [程序进阶路线](/guides/roadmap/intermediate/)
:::

## 两条分岔怎么选

| 你的目标 | 建议主路线 | 阶段 4 / 5 |
|---|---|---|
| 休闲 2D、UI 偏重、小游戏 | 阶段 1→2→3→**4**→6 | 阶段 5 只读概念入门即可 |
| 3D 玩法、角色场景、空间交互 | 阶段 1→2→3→**5**→6 | 阶段 4 读基础概念即可 |
| 都想了解 | 先完整走完一条，再补另一条 | 两条都做，但避免同时深入 |

:::note[和「快速入门」目录的关系]
本路线是**阅读顺序与学习策略**；「快速入门」里的章节是**详解正文**。路线页会把你指到正确的详解页，请在两个目录间来回跳转，而不是只盯一侧栏。
:::

打开下一篇 [准备环境与语言](/guides/roadmap/beginner/prepare/)，按步骤搭好环境与语言基础，再顺着侧栏继续向后学。
:::
