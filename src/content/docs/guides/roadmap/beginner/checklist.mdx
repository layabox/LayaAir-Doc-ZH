走到这里，你不必「学会全站」，但应能**独立完成一个小 Demo 的主循环**：建工程 → 摆场景 → 写脚本 → 预览调试 → 改到能玩。

## 能力对照清单

### 通用能力（必须）

- 能安装并使用 IDE，关联编码工具
- 能创建项目，说清场景 / 资源 / 脚本的大致位置
- 能给节点挂脚本，使用至少一个生命周期方法
- 能看懂控制台报错的第一条有效信息并定位文件
- 知道事件、定时器、资源加载各自解决什么问题

### 2D 主路线（选 2D 者必须）

- 能搭建简单 UI 层级并响应点击
- 配置过屏幕适配，并在异常比例下检查过效果
- 在模板或自建项目中改通过至少一处玩法逻辑

### 3D 主路线（选 3D 者必须）

- 能搭建「相机 + 灯光 + 网格/模型」的最小可见场景
- 理解变换的基本操作，能用脚本改位置或旋转
- 在模板或自建项目中改通过至少一处手感/玩法参数

:::tip[如何判断「学会了」]
把文档合上，从新建空项目开始，在 60～90 分钟内做出一个极简可运行 Demo。能做到，就说明新手路线达标。
:::

## 新手高频踩坑（提前避雷）

| 现象 | 更可能的原因 | 建议 |
|---|---|---|
| 预览是黑的 / 什么都没有 | 3D 没灯或相机朝向不对；2D 节点在屏外或缩放为 0 | 先核对相机/灯光/坐标，再查脚本 |
| 改了脚本没反应 | 未保存、未挂到节点、挂错对象、运行的不是该场景 | 看层级面板组件列表 + 启动场景配置 |
| 点击没响应 | 被上层节点挡住、`mouseThrough` / 点击区域理解偏差 | 读 [鼠标交互](/basics/performanceoptimization/mouse/) |
| 真机变形或留黑边 | 设计宽高与适配模式不匹配 | 读 [屏幕适配](/basics/common/adaptscreen/) |
| 一堆红字不知从哪看 | 从**第一条**错误追，忽略后续连锁报错 | 配合 [控制台](/basics/ide/console/) / [DevTools](/basics/devtools/) |
| 想一口气读完物理/Shader | 范围过大导致放弃 | 主线先通，扩展点到为止 |

## 回到文档站的正确姿势

1. **遇事搜索**：关键词用引擎类名或中文功能名均可。
2. **核对版本**：左上角版本分支与你的引擎一致。
3. **目录当地图，路线当指南**：本路线可随时回看阶段页，重新校对学习顺序。
