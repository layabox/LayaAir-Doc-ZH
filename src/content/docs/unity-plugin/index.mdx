本表基于插件源码逐模块核查整理，列出 Unity 各功能能否导出到 LayaAir 3.0 及其支持程度。关键且复杂的导出流程可点击各节的「查看导出流程 →」进入对应详情页。

- **插件版本**：1.1.7
- **入口**：Unity 菜单 `LayaAir3D 3.0 / Export Tool`
- **导出根模式**：整场景 Scene / 预制体 Sprite3D

:::tip[第一次使用？]
先看[安装与导出窗口介绍](/unity-plugin/install/)，了解安装步骤与导出窗口各控件的含义。插件的官方介绍见 [Unity资源导出插件](/3d/advanced/unity/)。
:::

## ⑤ 粒子系统 Shuriken

GPU / CPU 两条互斥路径，按对象自动选择。 [查看导出流程 →](/unity-plugin/particle/)

| Unity 模块 | GPU 模式 | CPU 模式 | 说明 |
| --- | --- | --- | --- |
| Main / Emission / Shape | 部分 | **完整** | GPU 下曲线降级为常量、Shape 部分类型回退球形 |
| Velocity / Color / Size / Rotation over Lifetime | **完整** | **完整** | 四种曲线模式均支持 |
| Texture Sheet Animation | 部分 | 部分 | 仅 Grid 模式，不支持 Sprites 模式 |
| Renderer（Billboard / Stretch / Mesh） | **完整** | **完整** | 5 种渲染模式 |
| Trails 拖尾 / Noise / Collision / Limit·Inherit Velocity / Force / by Speed / External Forces / Sub Emitters | 不支持 | **完整** | **启用 Trails / Noise / LimitVelocity 时自动强制切到 CPU 模式**，因此正常不会真的丢失 |
| Lights / Trigger / Custom Data | 不支持 | 不支持 | 两种模式都不导出 |

## ⑩ 明确不支持的组件

导出时检测并在控制台/对话框警告，但**不阻断导出**，相关功能静默丢弃：

Rigidbody 刚体 · Box/Sphere/Capsule/Mesh Collider 碰撞器 · CharacterController 角色控制器 · Joint 所有关节 · AudioSource 音频源 · AudioListener 音频监听 · TrailRenderer 拖尾渲染器 · LineRenderer 线条渲染器 · Cloth 布料 · WindZone 风区 · Canvas uGUI 画布 · VideoPlayer 视频 · Terrain 地形

:::note
**TrailRenderer（独立拖尾组件）**不导出；但**粒子系统的 Trails 拖尾模块**可导出（见 ⑤ 粒子系统，启用时自动走 CPU 模式）。LayaAir 引擎本身具备拖尾能力，此处为插件未做该组件的转换。
:::
