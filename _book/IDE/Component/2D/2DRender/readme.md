# 2D渲染组件

2D渲染组件，当前有6个，分别是2D网格渲染器、Spine渲染器、2D拖尾渲染器、2D线渲染器、2D粒子渲染器、瓦片地图层。

注意：基于性能考虑。同一个节点，仅支持添加一个渲染组件。
