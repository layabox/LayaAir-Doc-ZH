# 脚本集定义

> Author: Charley

脚本集定义文件 （Script Bundle Definition）是一种 `.bundledef` 格式的配置文件，用于定义和管理一组相关的脚本文件集合。在项目中使用脚本分包时，如果该分包包含脚本集定义文件，构建发布系统会在构建阶段根据这些配置文件的信息，将相关的 `TypeScript` 源文件**统一编译并打包为一个输出脚本文件（`.js`）**。

## 1、基础使用流程

### 1.1 创建脚本集定义 

脚本集定义文件（ `.bundledef` ）通常放在分包目录内，在项目资源面板中，通过 **右键目录 → 创建 → 脚本集定义** 即可生成，如图1-1所示。

![](img/1-1.png)  

（图1-1）

### 1.2 使用脚本集定义

选中脚本集定义文件`.bundledef`，可在属性面板中进行配置，最后点击应用，让配置的属性成功保存，如图图1-2所示。

![](img/1-2.png) 

（图1-2）

> 具体的属性作用将在第2小节中介绍

在属性面板中配置好后，选择或拖拽脚本集定义文件，在分包配置的入口脚本属性中使用，如图1- 3所示，用于实现代码分包的需求。
