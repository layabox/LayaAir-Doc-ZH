# 文本 （GTextField）
Author: 谷主

<img src="img/1-1.png" alt="1-1" style="zoom:60%;" />

- `Is Demo` Text设置的内容只作为Demo，也就是只在IDE编辑时显示，发布时将自动清空。
- `Fit Content`
  - `None` 无。文字组件尺寸无需匹配文本实际大小。
  - `Both` 同时。文字组件的宽度和高度都根据文本实际大小调整。
  - `Height` 高度。文字组件的高度根据文本实际高度调整。

其他属性和引擎的Text组件含义一致，可参考引擎文档，在此不再赘述。

输入文本是对引擎Input组件的封装，所有属性和引擎的Input组件含义一致，可参考引擎文档，在此不再赘述。
