然后在IDE的 开发者——包管理器 顺序安装插件。

3、使用 LayaIdea 的 AI 功能

3.1 服务订阅与代币充值

3.1.1 查看/订阅

点击工作区右上角的【查看/订阅】文字链按钮，可进行功能的开通或查看相应服务信息。

（图6-1）

3.1.2 代币充值

代币作为本平台内使用AI功能的消耗品（类似其它AI服务的 Token），有多种获取渠道：

  • 充值获取代币：点击管理平台界面右上角的充值按钮，可进入代币充值界面。
  • 订阅赠送通用代币：部分平台提供的订阅服务，会赠送一定数额的通用代币，这种通用代币可以用于平台内各种消耗代币的服务。
  • 代币扣除规则：赠送的通用代币 ＞ 充值获取的代币。

（图6-2）（图6-3）

3.4.2 需求分析

需求分析模块用于帮助用户分析游戏需求，生成结构化需求文档，并提供相关配置选项，支持多种分析深度选择。

方式1：

点击右侧悬浮按钮中的 📋 图标，进入界面之后 双击编辑区域，输入需求后点击 保存需求。

然后在底部聊天窗口输入 /build，或者点击底部的 / 按钮，选择箭头所示技能，发送给聊天就可以自动开始你的游戏制作了。

| | |

（图11-1）（图11-2）

方式2：

在聊天输入框中输入带"需求"相关的文本内容，发送给聊天。例如：

4、FAQ

如何开始制作游戏

直接在聊天输入框中输入带"需求"相关的文本内容，发送给聊天即可。例如：我要制作一个游戏，需求如下：xxxxx......。

如何管理项目资源

点击右侧功能按钮打开资源管理面板，可浏览、筛选和管理项目资源。

替换模型资源后，场景中的模型变成了白模（没显示贴图）

导入模型资源前，需要先将模型的贴图进行导入（批量拉取模型资源时同理，需前置拉取贴图文件）。如果出现白模情况，只需要再重复一次导入贴图——替换模型即可恢复贴图显示。

使用引用方式精准描述资源替换需求

在聊天中需要替换资源时，建议通过引用操作配合自然语言描述来组织替换逻辑：

  1. 先在场景节点或项目资源目录中点选需要替换的目标对象，点击聊天窗口中的引用按钮将其插入聊天。
  2. 再用自然语言描述替换需求，例如：将这个模型替换为AI生成的新模型。

AI会根据引用的对象和描述，自动完成节点/预制体与AI生成资源之间的替换操作。

将使用的资源在资源清单中列出

直接与AI对话，明确告知将目标资源列入资源清单，这样等资源列入清单后就方便对资源进行替换管理了。

API_KEY 丢失或忘记了怎么办

API_KEY 明文仅在创建时展示一次，无法再次查看。如果丢失，请前往接口密钥界面重新创建一个新的 API_KEY，然后在相应使用位置重新填入。

安装插件后右侧没有出现聊天窗口怎么办

LayaIdea 插件安装过程需要几分钟，请耐心等待 IDE 布局刷新完成。如果长时间未出现聊天窗口，可尝试按 Ctrl+Alt+R 刷新编辑器，或通过顶部菜单栏【开发者——刷新编辑器】手动刷新。

MCP Tools 显示连接异常怎么办

通过【文件——项目设置】进入项目设置，在【MCP Tools】中确认 Ide-tools、Laya-ide-mcp-server、laya_mcp_server 三项服务是否都处于正常连接状态。如有异常，先尝试刷新编辑器（Ctrl+Alt+R）。若仍未恢复，可尝试重新安装 LayaIdea 插件。

普通模式和专业模式有什么区别？该选哪个

普通模式UI和技能等操作选项较为简洁，适合快速上手。专业模式在此基础上增加了 #自定义快捷指令、设置偏好、需求分析、资源管理 等高级功能，适合有明确项目需求、需要精细控制生成流程的用户。可通过顶部标题栏右侧的齿轮图标随时切换。

AI 生成的资源在哪里？为什么找不到了

通过聊天窗口生成的资源，需要手动点击缩略图右下角的 下载 按钮，资源会保存到项目资源目录下的【aigc_res】文件夹内（2d 和 3d 资源分别存放在对应子目录中）。另外请注意，历史记录仅保留2天，请及时下载所需资源。

切换模型后设置没有生效

在设置偏好中切换模型后，保存设置 按钮会变为 重启IDE后生效，需要点击该按钮立即重启 IDE，模型切换才会生效。

代币不够用了怎么补充

通过聊天窗口右上角的【查看/订阅】，可以打开管理后台，点击管理后台界面右上角的充值按钮，即可进入代币充值界面。此外，部分订阅服务会赠送通用代币，系统会优先消耗赠送代币，再消耗充值代币。
