IDE快捷键与鼠标交互操作大全

Author: charley

IDE 的基础交互分为键盘输入、快捷键、鼠标交互、鼠标与键盘的功能组合。

本篇介绍 IDE 的基础交互与默认快捷键，便于双手协作、提升开发效率。除非特别说明，下列为 Windows 默认键；Mac 上 Ctrl 对应 Command（源码中以 mod 表示跨平台修饰键）。

本篇所列多为 IDE 出厂默认值。绝大多数可在菜单 编辑 → 偏好设置 → 快捷键 中查看与修改（详见第 6 章）。文中以 Windows 为例书写。

1、通用的基础交互

Section titled “1、通用的基础交互”

层级面板、属性面板、项目面板等几乎处处会用到，因此先介绍通用交互与全局快捷键。

1.1 切换面板显示层级

Section titled “1.1 切换面板显示层级”

IDE 功能面板可任意拖拽布局；同一窗口内，点击面板标签可切换显示层级，如图1-1所示。

（图1-1）

除了点击标签，还可用下列快捷键聚焦常用面板：

功能名称操作
场景面板 SceneCtrl + 1
运行面板 GameCtrl + 2
属性面板 InspectorCtrl + 3
层级面板 HierarchyCtrl + 4
项目资源面板 ProjectCtrl + 5
控制台面板 ConsoleCtrl + 6
时间轴面板 TimelineCtrl + 7

1.2 全局编辑与文件、节点操作

Section titled “1.2 全局编辑与文件、节点操作”

1.2.1 撤销、重做与保存

Section titled “1.2.1 撤销、重做与保存”
功能名称操作
撤销Ctrl + Z
重做Ctrl + Y，或 Ctrl + Shift + Z
保存Ctrl + S

保存为全局快捷键，后文各模块不再重复说明。Mac 上删除除 Delete 外，还可用 Command + Backspace。

1.2.2 重命名：F2

Section titled “1.2.2 重命名：F2”

无论是节点名还是文件、文件夹，使用快捷键 F2 即可进入重命名模式。

鼠标操作：单击选中 后间隔约半秒再 单击，效果等同于 F2。

1.2.3 复制、剪切、粘贴、删除、选中

Section titled “1.2.3 复制、剪切、粘贴、删除、选中”

在层级面板、项目面板、场景面板等位置，选中节点或文件后可用：

功能名称操作
拷贝Ctrl + C
剪切Ctrl + X
粘贴Ctrl + V
原位粘贴Ctrl + Shift + V
粘贴为子节点无默认键，可在偏好设置中绑定
删除Delete（Mac 亦可用 Command + Backspace）
全选Ctrl + A
选中单个鼠标左键单击
多选Ctrl + 鼠标左键单击
不间断多选Shift + 鼠标左键单击

1.3 层级面板的常用操作

Section titled “1.3 层级面板的常用操作”

1.3.1 创建空节点

Section titled “1.3.1 创建空节点”

除右键菜单外，可用快捷键快速创建空节点：

功能说明操作
在根节点下创建一个空子节点Ctrl + Shift + N
为当前选中节点创建一个空子节点Alt + Shift + N
为当前选中节点（可多选）创建一个空父节点Ctrl + Shift + G

2D 空节点为 Sprite，3D 空节点为 Sprite3D。

6、在偏好设置中自定义快捷键

Section titled “6、在偏好设置中自定义快捷键”

菜单 编辑 → 偏好设置，打开后选择 快捷键（对应类型 ShortcutKeys），即可查看与修改默认绑定，分组大致如下：

分组涵盖内容示例

本篇未穷尽「无默认值、仅允许自定义」的全部项（如停止播放、单步帧、粘贴为子节点等），以偏好设置面板列出的条目为准。
